# Gestão de Frete

Controle de tickets, fechamentos e pagamentos de fretes (React + Vite + Supabase).

## Visual SISPRÓ
- Menu lateral azul-marinho, destaque laranja, fundo creme (tema escuro disponível no botão do topo).
- Faixa de etapas: Lançar → Fechar → Solicitar → Pagar.
- **Efeito espelho** (`.mirror`): vidro refletindo a luz, brilho que segue o cursor e varredura de luz.
- **Gráfico no hover**: passe o mouse (ou toque/foque com Tab) nos indicadores para ver a evolução por dia, semana ou mês.
- Estilos em `src/sispro.css`; nome da marca em `src/Brand.jsx`.

## Rodar
```bash
pnpm install   # ou npm install
pnpm dev
pnpm test
```
Configuração da nuvem: veja `CONFIGURAR-NUVEM.md`.
